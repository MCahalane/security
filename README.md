# Lesson 6 · Information Security

A self-contained interactive Chapter 4 companion for U.S. business students, matching Lesson 5’s blue, purple and green visual style and six-stage learning pattern.

## Open and use

Open index.html in a browser. Keep assets/cafe.webp in its folder. No installation or build is required. A local or hosted web server provides the most consistent browser storage behavior. The written lesson works offline; YouTube and sources require internet.

The package includes six retryable checks, explanatory feedback, seven short video pauses, U.S. and Australian cases, an interactive fictional risk estimate, local draft saving, a worksheet download, a read-all view, print support, and instructor notes. Browser storage is specific to the browser and origin and may be unavailable for local files or private browsing.

## Content and evidence

Core coverage follows Chapter 4 sections 4.1–4.5. Contemporary additions are labeled. Case sources were checked September 30, 2026. The Qantas case includes the July 2026 OAIC update. AI use is documented for the impersonation examples, not asserted for Qantas or Change Healthcare. The café and its risk figures are fictional. The supplied Lesson 5 café illustration is reused; its README identified it as AI-generated.

Titles and publishers were found in indexed records; full playback, exact full duration, caption and embedding availability were not verified. Preview on the teaching network before class. ## Publishing

This package is ready for an existing static host or the same GitHub Pages workflow as Lesson 5. Upload index.html, assets/ and .nojekyll at the chosen location. It has not been published by this task. No textbook PDF or source extracts are included in the distributable ZIP.

## Privacy and editing

There is no lesson analytics, account system, server submission or grading service. Local drafts can be downloaded and reset. Loading YouTube contacts an external provider. Hosting services may process normal access information. Instructor notes and worked answers are visible to students by design.

Edit index.html to revise wording, questions or sources. The new module’s styles and interactions are in assets/cognitive-security.css and assets/cognitive-security.js. Check all six stages, keyboard use, mobile layout, local persistence, download and print after changes. News sources and linked media should be rechecked before later offerings.

### Private check-up

Check-up choices and plan text remain in memory until Save is selected. The independent local-storage key is lesson6-cognitive-plan-v1. Later edits require Save again. Clear removes this check-up key; the lesson-wide Reset clears it as well. Private plan downloads are separate from the café worksheet; neither is uploaded by the lesson. Local storage is not encrypted and can be accessible to other users of the same browser profile. Printing includes current private plan text: review before sharing. Downloaded files must be managed separately.

### Accessibility and fallback

Native buttons, selects, checkboxes and details support keyboard interaction. Dynamic results use polite status announcements. No timers, forced motion, audio or autoplay were added. New layouts collapse for narrow screens. Read-all expands the new written debriefs; printing expands all details. Without JavaScript, the six stages remain visible, all new activities have written alternatives, and original quiz questions include static options and explanations. A written default risk calculation is also provided.
